# ПЛАН МОДЕРНИЗАЦИИ «ГОЙДА-ИМПЕРИЯ» → игра уровня Tropico

Составлен 2026-08-11. Синтез: аудит кода (проверено), отчёт Gemini Deep Research (отфильтрован),
дизайн-вердикт Codex `gpt-5.6-terra`.

**Решение по стеку:** остаёмся на Three.js, доводим перф, затем упаковка в **Electron**
(не Tauri — Tauri отдаёт рендеринг системному WebView2, версия которого зависит от машины игрока;
для тяжёлой WebGL-сцены это лотерея. Electron везёт свой Chromium: что протестировали, то игрок
и получит. Размер дистрибутива как аргумент не работает — целевой бюджет и так пара гигабайт).

**Признак, что решение пора менять:** после Фазы 1 при 300 агентах FPS остаётся ниже 30.
Тогда — Godot 4, но уже с готовым дизайном на руках.

### Baseline (после Фазы 1.1 spatial hash + 1.2 убран второй WebGL-контекст, ДО 1.3/1.5)

Замерено в Playwright/Chromium headless локально (`http://localhost:7842`), каждый уровень —
чистый рестарт кампании + один вызов `__stress(n)`, чтобы не путать с гибелью ратуши между замерами.
FPS в headless занижен троттлингом фонового таба Chrome — ориентир по нему давать нельзя,
но **тик и рендер в мс — реальные и сопоставимые**.

| Юнитов | тик, мс | рендер, мс | draw calls | tris |
|---|---|---|---|---|
| 53 | 3.19 | 17.82 | 777 | 79 836 |
| 154 | 5.14 | 27.72 | 1558 | 96 726 |
| 301 | 9.07 | 40.89 | 2523 | 115 744 |

Тик растёт почти линейно (3.19 → 9.07 мс на 53 → 301, то есть ×2.8 при ×5.7 юнитов) —
spatial hash работает, квадратичного роста больше нет. Рендер растёт быстрее тика и уже
на 301 юните держит ~41 мс сам по себе (это где InstancedMesh из 1.5 даст основной эффект:
сейчас каждый юнит — отдельный draw call, отсюда 2523 draws на 301 агента).

**Побочный баг, найден и исправлен по ходу замера**: `engine/Renderer.js` рендерит через
`EffectComposer` с несколькими внутренними проходами (RenderPass, bloom, tonemap, grade, tilt,
SMAA) — каждый внутренний `renderer.render()` по умолчанию сбрасывает `renderer.info`, поэтому
профилировщик до фикса видел только последний проход (SMAA, полноэкранный треугольник) —
отсюда фантомные `draws=1 tris=1`. Исправлено: `renderer.info.autoReset=false` +
ручной `reset()` в `beginRender()` (`engine/Profiler.js`, `?v=95`).

**Не баг, а факт геймплея**: `__stress()` спавнит в обход гейта Waves.js «нет набегов без
казармы/ранга/воинов» — на пустой базе 50+ агентов кладут ратушу за секунды. Это ожидаемо
для тестового инструмента, не свидетельство о жалобе игрока на ранний набег (та жалоба —
про обычный игровой спавнер, который гейт уже соблюдает).

## Правила работы

- Импорты версионируются вручную: `./file.js?v=94`. Новые файлы — с тем же параметром,
  при правках версию поднимать, иначе GitHub Pages отдаст закэшенное.
- `package.json` нет и не заводим до Фазы 4 — проект остаётся статикой.
- Проверка — программная: `node --check` по синтаксису, счётчики профилировщика по перфу.
  Скриншот только там, где правка визуальная.
- Запуск локально только через HTTP (ES-модули + importmap не работают с `file://`).
- Не коммитить и не пушить без явной команды игрока.
