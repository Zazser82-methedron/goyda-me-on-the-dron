# Арт-пайплайн карт — заметки на будущее

## Что выяснили (PoC, 2026-06)
Пробовали генерить арт карт через **Canva MCP** (`generate-design` → `create-design-from-candidate` → `export-design` PNG). Вывод: **не подходит**. Canva — это инструмент *дизайна*, а не генератор картинок: на выходе получается готовый **постер с текстом** (заголовки, адрес, RSVP) и водяным знаком «Canva» (free-tier), а не чистая иллюстрация персонажа/предмета. Сама картинка — лишь маленький элемент внутри макета. Для арта карт это тупик независимо от промпта.

Текущее решение: **CSS/SVG глоу-ап** карт прямо в `index.html` (рамки, фольга-блик, свечение по редкости, гербы) — без внешних ассетов и хостинга. Редкость считается из `cnt`: `<=2` легендарка, `3` эпик, `4` редкая, `>=5` обычная (`rarityOf()` в коде).

## Что нужно для настоящего рисованного арта (когда будешь готов)
Нужен **text-to-image MCP** (генератор картинок), а НЕ Figma/Canva. Варианты сервера:
- **Replicate MCP** — доступ к Flux / SDXL / др. моделям. Нужен токен `r8_...` с replicate.com.
- **OpenAI Images (gpt-image-1) MCP** — нужен ключ OpenAI.
- Локальный **ComfyUI / Stable Diffusion** через MCP-обёртку (без оплаты по API, но нужен GPU).

### Шаги интеграции (черновик)
1. Подключить выбранный image-MCP в Claude Code (`claude mcp add ...` или через настройки коннекторов), дать API-ключ.
2. Сгенерировать 15 карт в едином стиле. Промпт-шаблон (без текста!):
   > «single centered fantasy game-card illustration, no text, isolated subject on transparent/dark background, Slavic-neon style, crimson+gold palette, painterly, glowing edges — subject: <описание под карту>»
   Описания по картам: ГОЙДА — воин с неоновым мечом; ГИПЕР-ГОЙД — молния/гипер-энергия; ГОЙДУШКА — фея-целительница; ЩИТ — рунический щит; и т.д.
3. Скачать PNG в `goyda-me-on-the-dron/art/<ID>.png` (`curl` по URL экспорта). Сжать (TinyPNG/`pngquant`) — следить за весом репо.
4. В коде уже всё готово к подключению: добавить поле `img:'art/<ID>.png'` в `DEFS` и в эмблеме карты рендерить `<img class="card-art" onerror="откат к эмодзи">`. Если файла нет — текущая эмодзи-иконка (graceful fallback).

### Анимации (отдельно)
Для анимированных карт/эффектов уже подключён **HeyGen HyperFrames MCP** (HTML→видео MP4/WebM). Подходит для трейлеров/заставок, не для статичных гербов. Для внутриигровых анимаций проще CSS/Canvas (как текущие искры/тряска).

## Итог
- Сейчас: визуал на CSS/SVG — быстро, без зависимостей, темируется под косметику.
